(3) Show me the green output with the change. (4) Run the regression suite for the neighbouring items and show me it is still green. (5) Run the end-to-end test of the flow this item touches, from the screen to the backend, and show me the backend effect. (6) Do not replace with mocks the very part you are trying to test. If testing end to end requires something you lack (data, access, an environment), ask me for it; do not simulate what you do not have. If the previous version does not have the module at all (the first block of a new project), a failure to load is not a red: prove the red by planting one deliberate defect in the function you just wrote (an inverted condition, a deleted line), show me the test failing against that defect as the same kind of receipt, with the diff of the defect, and then revert it.
