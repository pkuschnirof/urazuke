# 台阶契约

每级台阶一个文件。所有文件都有相同的骨架：标题栏包含阶段、形式和规模（必需或按比例）；
用途；(1) 所需上下文，以通用方式命名；(2) 提示词，**英文**，每条之后用读者的语言解释我们
在要求什么、为什么每个条款都在那里；(3) 预期结果及其特征；(4) 完整性检验，所有者不读代码
即可完成；(5) 警报信号，台阶没登好的症状。

英文提示词是单一原件，在八种语言的所有文档版本中完全相同；`node build/build.mjs` 将它们
提取到 `prompts/`，并检验没有任何翻译改动了它们。

它们是根据我们在三个仓库中实际做过的事写成的，尚未按原样执行过。第一个从头到尾使用它们
的项目会修正其中若干条：那是第 15 级台阶的一部分。
