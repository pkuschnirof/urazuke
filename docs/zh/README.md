# Urazuke — 验证方法

*Urazuke*（裏付け）是一个日语词，指一个断言所拥有的依据：从背后支撑它的东西。动词
*urazukeru* 的意思是"用证据支撑"。这就是这个方法。

一种用人工智能构建软件的方法，产出的软件稳健、可投入生产，而且**项目的所有者不必读一行
代码**。它从三个如今正在生产环境运行的真实系统中提炼而来，包括那些惨痛的教训。

本文件夹包含方法的中文版。西班牙语是事实来源；若两个版本有出入，以西班牙语版为准，并
修正中文版。

## 一句话的论点

AI 没有中断方法：它延续了方法。业界在二十年前就不再信任代码的作者，并学会了索要证据而不
是读代码；模型是下一位作者，而不是第一位需要被怀疑的作者。唯一真正新的东西是，这位作者
也制造证据，因此证据必须证明它自己。

## 如何阅读

从 `ESCALERA_METODOLOGICA.md` 开始，或者从 `../html/zh/` 中的 HTML 版开始。遇到陌生的词，
术语表在末尾。然后再读你感兴趣的那级台阶的契约。

## 语言

西班牙语是事实来源。文档存在于 NAC3 的八种语言中（西班牙语、英语、葡萄牙语、法语、德语、
意大利语、日语和中文）。给模型的提示词是英文的单一原件，在所有版本中完全相同，并用读者的
语言加以解释。名字不翻译；副标题翻译：*el método de la evidencia*、*the evidence method*、
*o método da evidência*、*la méthode de la preuve*、*die Nachweis-Methode*、*il metodo del
riscontro*、裏付けの方法、验证方法。

本方法以 **知识共享 署名-相同方式共享 4.0** 许可（`../../LICENSE`）发布：可以使用、翻译和
