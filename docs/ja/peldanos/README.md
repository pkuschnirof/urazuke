# 段の契約

段ごとに一ファイル。すべて同じ骨格です。ヘッダにフェーズ、形式、規模（必須か比例か）。
何のためか。(1) 必要な文脈、一般的な名前で。(2) プロンプト、**英語**で、それぞれの後に
読者の言語で「何を求めているのか、なぜ各条項があるのか」の説明。(3) 期待される成果物と
その特徴。(4) 完全性の検証、オーナーがコードを読まずに行うもの。(5) 警告サイン、段を
登り損ねた兆候。

英語のプロンプトは単一の原本で、八言語すべての版で同一です。`node build/build.mjs` が
それらを `prompts/` に抽出し、どの翻訳もプロンプトを変えていないことを検証します。

これらは三つのリポジトリで実際に行ったことから書かれたもので、このままの形でまだ実行
されたことはありません。最初から最後までこれを使う最初のプロジェクトが、いくつかを
修正するでしょう。それは第15段の一部です。

名はビルドツールが認識できるよう、すべての言語でスペイン語のままです。
