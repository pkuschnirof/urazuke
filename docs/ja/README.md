# Urazuke — 裏付けの方法

*Urazuke*（裏付け）とは、ある主張を背後から支えるもの、つまり根拠のことです。動詞の
*裏付ける*は「証拠で支える」という意味です。これがこの方法の名前です。

人工知能でソフトウェアを構築し、それが堅牢で本番運用に耐え、しかも**プロジェクトの
オーナーがコードを一行も読まずに済む**ための方法です。現在本番稼働している三つの実在する
システムから、手痛い失敗も含めて蒸留したものです。

このフォルダには方法の日本語版が入っています。スペイン語版が正本です。両者が食い違う
場合はスペイン語版が優先され、日本語版が修正されます。

## 一文で言うテーゼ

AIは方法を中断しない。方法を継続する。業界は二十年前にコードの書き手を信用することを
やめ、コードを読む代わりに証拠を要求することを学んだ。モデルは「次の書き手」であって、
「初めて疑うべき書き手」ではない。本当に新しいのはただ一つ、この書き手が証拠までも
作り出すということ。だから証拠は、証拠自身を証明しなければならない。

## 読み方

`ESCALERA_METODOLOGICA.md` から、または `../html/ja/` のHTML版から始めてください。見慣れ
ない言葉に出会ったら、末尾の用語集を参照してください。その後、関心のある段の契約へ。

## 言語

スペイン語が正本です。文書はNAC3の八言語（スペイン語、英語、ポルトガル語、フランス語、
ドイツ語、イタリア語、日本語、中国語）で存在します。モデルへのプロンプトは英語の単一の
原本で、すべての版で同一であり、読者の言語で説明されます。名前は翻訳しません。副題は
翻訳します：*el método de la evidencia*、*the evidence method*、*o método da evidência*、
*la méthode de la preuve*、*die Nachweis-Methode*、*il metodo del riscontro*、裏付けの方法、
验证方法。
